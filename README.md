## Preview Locally

1. Open `index.html` directly in your browser, or run a lightweight local server (for example, using Python):

   ```bash
   python3 -m http.server 8000
   ```

2. Then visit `http://localhost:8000`.

## Deployment

Any changes pushed to the `main` branch are automatically built and deployed by GitHub Pages to [https://tylerrollo.github.io](https://tylerrollo.github.io).
